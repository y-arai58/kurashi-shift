# 全国支援情報の収集・更新フロー

作成・初回収集日：2026年9月7日

## 1. 初回収集の範囲と限界

全国共通10制度の公式情報を確認し、診断・条件検索・制度詳細へ接続しました。既存の福岡市独自4制度と合わせて14制度です。追加した9制度は、入口条件が一致しても個別の収入・認定など未照合の条件を残し、受給確定とは表示しません。

JOINの47都道府県ページから1,506地域の情報入口を収集しました。これは全国の全市区町村・全制度を網羅した件数ではなく、掲載されている地域へのリンク数です。地域ページ内の制度条件・受付状況はまだ確認していません。自治体公式ページとは区別し、診断件数へ加算しません。

情報入口の出典：[JOIN 都道府県情報](https://www.iju-join.jp/prefectures/)（公益社団法人ふるさと回帰・移住交流推進機構）。自治体から提供された情報でも古い条件を含み得るため、個別制度は自治体の一次資料を別途確認します。

## 3. 毎月の収集手順

1. 前回記録と途中変更を確認する。利用者の編集を上書きしない。初回以外は、前回の収集結果を比較元として残す。
2. リポジトリで `npm run collect:monthly` を実行する。Node.js 24を使用。47都道府県の情報入口と、掲載14制度の公式ページを順次取得する。
3. 新規・変更・取得失敗を確認する。HTTP成功でも本文取得は内容の確認ではない。ハッシュ変化にはメニュー等の変更も含まれるため、人が制度の変更か判断する。
4. 全国制度を優先して一次資料を読む。年度、対象者、受給単位、所得と収入の定義、審査対象者、居住地、転入元・転入先・転居時期、期限、予算終了、併用・除外・必要書類を確認する。
5. 地域独自制度の収集を進める。各都道府県内の地域入口から自治体公式サイトへ移り、子育て、住居、就業、教育、年金・生活困窮、移住などの個別制度を抽出する。外部リンクはデータとして扱い、取得先の利用条件や負荷に配慮する。
6. 条件を制度レコードへ整理し、質問で答えられる条件と個別認定が必要な条件を分ける。未確認事項を推測して埋めない。新しい質問が必要なら利用目的と表示条件も追加する。
7. 差分レポートを保存する。確認済み件数、未確認件数、取得失敗、廃止の根拠、次回の再開地点を記録する。条件・確認日・公開データの変更はレビューと承認を待つ。
8. 承認後に判定・条件ガイド・質問・確認日を一緒に更新し、テスト、型検査、ビルドを実施する。更新内容を履歴へ保存してから同じソースを公開する。問題時は直前の確認済み版へ戻す。

月1回の確認では、月の途中の予算終了・短期募集を即時検知できません。制度詳細の公式リンクと確認日を残し、この制約を案内します。

## 4. 記録と判定の原則

- 全国制度、都道府県制度、市区町村制度は別の適用範囲として扱う。全国制度の自治体案内ページを別制度として重複計上しない。
- 現在地と転居先、現在と仮定のプロフィールを分ける。地域情報が未収集でも「制度0件」「全制度を失う」としない。
- `fetchedOn` は機械が取得した日、`verifiedOn / lastVerified` は条件を確認した日、`sourceUpdatedAt` は出典に書かれた更新日。相互に代用しない。
- `reviewAfter` は再確認期限。内容の確認後に設定し、期限を過ぎたら未確認扱いにする。
- 取得失敗・URL変更・検索結果のキャッシュは、制度廃止の根拠ではない。以前の確認済み情報を保持し、失敗をレビュー待ちとして記録する。
- 地域入口は `eligibilityReviewed: false`。実施主体の個別一次資料で確認するまで診断データへ昇格させない。
- 入力を省略した場合は不一致としない。ただし入口質問に未回答だと候補を絞れない制度があるため、回答追加と条件検索を案内する。
- 金額は一時金・月額・減免・上限を分け、合計金額を作らない。

## 5. 保存場所と再開方法

- `scripts/collect-regions.mjs`：47地域ページのリンク一覧を取得、差分と失敗を保存。
- `scripts/collect-official.mjs`：掲載制度の公式URL、最終到達URL、取得状態、本文ハッシュを保存。条件の自動抽出・自動改定はしない。
- `data/collection/YYYY-MM-DD-regions.json` と `regions-latest.json`：地域入口の収集記録。
- `data/collection/YYYY-MM-DD-official.json` と `official-latest.json`：公式ページの取得記録。
- 同日の再実行は日付ファイルを更新するため、再実行前の記録はGitの履歴等で保全する。
- `lib/national-programs.ts`、`lib/programs.ts`：診断用の確認済み要約と照合条件。
- `lib/national-profile.ts`：今回増やした初回質問。
- `lib/official-guidance.ts`：サイト内で検索する条件の説明。
- 検証：`npm test`、`npx tsc --noEmit`、対象ファイルのlint、`npm run build`。

次回の未処理範囲は「47都道府県それぞれの自治体公式の個別制度」です。1,506地域入口の抽出完了と、個別制度の条件確認完了を混同しません。県別に地域ID・公式URL・状態（候補／確認待ち／確認済み／取得失敗）・最終処理地点を台帳へ追記して進めます。現行の入口IDはJOINの識別子であり、全国地方公共団体コードではありません。

## 6. 初回質問を増やした理由

従来の必須3問は維持し、次の12項目を任意で追加しました。該当時だけ表示する質問を含むため、全員に12問を表示するわけではありません。福岡市外では都道府県も任意で選択できます。

|追加する基本情報|主な用途|
|---|---|
|妊娠中・出産後の方がいるか|妊婦給付・出産費用・産休中の支援|
|現在の働き方|雇用・保険の案内、児童手当の公務員の申請先|
|出産する方の健康保険|出産手当金の本人・扶養の区別。妊娠・出産に該当するときだけ表示|
|離職・廃業・収入減少|住居確保給付金などの入口|
|家賃・住まいの負担|家賃補助・転居費用補助|
|世帯全員が住民税非課税か|保育料支援の案内。年収から推定しない|
|未就学の子どもの有無|幼児教育・保育無償化。子どもがいる世帯で表示|
|大学等への進学・在学|高等教育の修学支援|
|扶養する子どもが3人以上か|多子世帯支援。進学・在学がある場合のみ表示|
|職業訓練を検討しているか|求職者支援制度|
|国民年金保険料の負担|免除・納付猶予|
|転居の予定・検討|地域情報入口、転居費用支援|

初回には住所の番地、マイナンバー、証明書、正確な給与・資産額を求めません。収入・資産などの細かな審査は、制度ごとに説明して必要な範囲で確認する設計です。行政の審査そのものを代替する機能ではありません。

このタスクに、毎月1日9:00（日本時間）の収集を設定済みです。初回予定は2026年10月1日です。変化・取得失敗・判断が必要な場合に通知し、未確認の変更を自動公開しません。
